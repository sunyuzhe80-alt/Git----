# 代码与字段讲解：按程序实际顺序阅读

## 1. main.py：总入口

argparse 读取参数；Path 定位文件，默认数据路径基于 main.py 所在目录，不依赖你从哪个文件夹启动。main 依次读取价格、调用回测、计算指标、保存结果。只有直接执行本文件才运行，导入时不会自动回测。

## 2. data.py：整理原材料

csv.DictReader 按列名读取每一行。Date 转为日期，四个价格转为 float。检查缺列、空值、NaN、无穷大、非正价格、重复或乱序日期；有错误就停止，而不是悄悄删行或填值。

返回的每条记录类似：`{"date": 日期, "prices": {"AAPL": 价格, "IBM": 价格, ...}}`。CSV 的 GSPC 列没有用于策略。

## 3. factor.py：计算分数并选股

`rows[index]["prices"][symbol] / rows[index-lookback]["prices"][symbol] - 1` 就是过去 lookback 个交易日的涨跌幅。

`sorted(..., key=lambda symbol: (-scores[symbol], symbol))` 用负分数实现从高到低，同分再按代码排序。`ordered[:top_n]` 取前 top_n 个；选中的目标权重为 1/top_n，未选中为 0。

函数只访问 index 及以前的价格，不读取未来价格。未来成交日仅用于记录时间，不用于选股。

## 4. backtest.py：按天模拟账户

核心变量：

| 变量 | 含义 |
|---|---|
| shares | 每只股票的持有单位数，允许小数 |
| cash | 账户现金，不得借钱买入 |
| prices | 当天四股价格 |
| before | 按今天收盘价计算、尚未调仓扣费的账户价值 |
| pending | 昨日生成、今天收盘可以执行的名单 |
| weights | 这次调仓希望达到的权重 |
| deltas | 各股需买入或卖出的金额，正数买、负数卖 |
| fee | 本次所有买卖成本之和 |
| value | 当天收盘调仓后的账户价值 |

执行顺序：

1. 用旧持仓乘当天价格，加上现金，计算 before。
2. 如果有昨日名单，在今天收盘调仓并扣费。
3. 计算收盘账户价值、当天收益、净值并保存。
4. 若今天是固定信号日，计算名单，存进 pending，等待明天执行。

`market_pnl = before - previous_value` 是旧持仓当天的盈亏。`strategy_return = value / previous_value - 1` 已经包括当日交易成本。不要在报告中再次扣费。

## 5. rebalance：怎样避免全仓买入后钱不够付手续费

这部分是辅助记账函数，先理解业务含义再看二分法。

只有现金 100 元，单边成本 1%，全仓买入时不能买 100 元再另付 1 元，因为账户只有 100 元。正确可买金额为 `100 / 1.01 ≈ 99.0099`，余下约 0.9901 元用于费用。

已有持仓时，还可能同时卖出、买入。设扣费前账户价值为 E，扣费后为 V，各股目标金额为“目标权重 × V”。交易金额等于目标金额与原持仓金额之差的绝对值。因此：

`V + 单边费率 × 所有股票买卖金额之和 = E`

二分法在 0 到 E 之间逐步缩小 V 的范围：试一个中点，若“持仓金额加费用”超过 E 就把上界缩小，否则把下界提高。重复 80 次后得到浮点精度下的结果。不需要优化器或机器学习。

全换仓要卖旧股、买新股，两侧都收费；不是只对净流入金额收费。微小现金尾差归零是浮点数处理，不代表真实账户允许透支。

## 6. metrics.py / report.py：统计和输出

首行净值为 1，日收益为 0，是共同起点，不作为一个收益期参加年化计算。stdev 使用样本标准差，零波动时夏普不适用。最大回撤从初始净值开始维护历史峰值。

report 保存 CSV、JSON、Markdown 和 SVG；HTML 直接内嵌 SVG，无需互联网或画图库。年度收益是逐日连乘，不是简单相加。

## 输出字段如何核对

| 文件 | 重点字段和读法 |
|---|---|
| factor_rankings.csv | signal_date 为信息截止日；planned_execution_date 为下一交易日，末日无后续价格时为空；momentum 是小数收益；selected 为 1 表示入选 |
| daily_results.csv | market_pnl 是旧持仓当日盈亏；strategy_fee 是调仓费用；strategy_value 是扣费后总资产；*_units 为收盘持有单位数；*_weight 为实际收盘权重 |
| trades.csv | account 区分 strategy / benchmark；signal_date 与 date 分别为信号和成交日期；amount 是该股交易金额；fee 为该笔费用；units 为成交单位数 |
| rebalances.csv | traded_amount 包含买卖两侧；turnover_ratio = 买卖金额之和 / 调仓前账户价值，全部换股可接近 2，不是上限为 1 的单侧换手口径 |
| metrics.json | 收益率均为小数；费用为模型计价单位；data_sha256 用于核对输入数据是否变化 |

日记账恒等式：`今天总资产 = 昨日总资产 + 旧持仓今日盈亏 - 今天费用`。测试和最终核验都会检查。

## 常见基础语法

def 定义函数，return 返回结果；list 保存有顺序的记录，dict 按名字保存字段；for 逐个处理；if 判断条件；None 表示暂时没有值；append 在列表末尾添加；abs 取绝对值。带 `--` 的命令行参数用于修改默认设置，不必改源码。
