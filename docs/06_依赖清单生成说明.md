# 方法一：导出当前开发环境的已安装包

已按截图中的 `pip list --format=freeze` 方法导出，文件保存在项目根目录：`requirements_win11_Freeze.txt`。

使用解释器：`C:\Users\86198\anaconda3\envs\myEnvironment\python.exe`，Anaconda Python 3.6.13，pip 21.2.2。系统为 Windows，注册表 DisplayVersion=25H2、Build=26200，按 Windows 11 命名。部分兼容性接口或注册表 ProductName 仍会报告 Windows 10，不用它们替代实际构建号判断。

导出的是这个虚拟环境中全部通过 pip 可见的已安装包，不是电脑所有 Python 环境的包，也不是自动分析代码得到的最小依赖。

当前共 5 项：certifi、pip、setuptools、wheel、wincertstore。它们是环境现有组件，不意味着策略代码调用了这些第三方库。

在 PyCharm 选择同一解释器后，也可在终端通过下面的明确路径命令重做（PowerShell）：

```powershell
& "C:\Users\86198\anaconda3\envs\myEnvironment\python.exe" -m pip list --format=freeze
```

本次将上述标准输出以 UTF-8 写入文件，避免 PowerShell 重定向可能引入的编码差异。没有执行 pip install，也没有升级、卸载包或修改解释器。

原 requirements.txt 保留，用于说明项目只用 Python 标准库、无需第三方依赖；新 Freeze 文件用于记录完整开发环境快照，两者用途不同。
