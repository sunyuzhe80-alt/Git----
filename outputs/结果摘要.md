# 默认回测结果

评价区间：2007-02-01 至 2016-03-01。

| 指标 | 动量策略 | 四股买入持有 |
|---|---:|---:|
| 累计收益 | 161.84% | 314.54% |
| 年化收益 | 11.20% | 16.98% |
| 年化波动率 | 25.27% | 24.55% |
| 夏普比率 | 0.546 | 0.762 |
| 最大回撤 | 62.89% | 53.91% |
| 期末净值 | 2.618 | 4.145 |

本样本中策略累计收益比基准低 152.70 个百分点。这是两者累计收益之差，不是相对净值收益率，也不证明未来有效。

## 研究限制

四只事后选定股票存在选择及幸存者偏差，不能代表全市场；价格复权与分红处理未独立核验，不宣称含分红总收益；只做历史全样本描述，没有独立样本外验证。允许碎股、不借贷、不做空，未模拟真实成交限制、税务或汇率。

数据、模型和比较口径详见离线 HTML 报告及项目文档。
